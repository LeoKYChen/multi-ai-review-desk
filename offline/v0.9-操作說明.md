# Multi-AI 雙 AI 協作工作臺 v0.9｜離線版

> 本版新增「歷次回合與意見對照」，保留 v0.8 的原有工作流程及資料格式。
> 尚未連線 Cloudflare D1，也不會自動呼叫 ChatGPT 或 Gemini；每次模型回覆仍需手動貼回。

## 新增功能

1. **歷次回合切換**：在任務頁的「歷次討論／意見對照」選擇第 1、2、3……回合，查看當時的兩位 AI 回覆，而不是只能看最新回合。
2. **同一階段並排比對**：選擇「第一階段：獨立分析」、「第二階段：交叉審查」或「第三階段：最終修正建議」，同時閱讀 ChatGPT 與 Gemini 在該階段的內容；也可選擇全部三階段。
3. **人工決策歷程**：選擇任一回合即可閱讀該回合的採納／退回決定、理由與日期，頁尾可直接點選歷次回合。
4. **避免誤操作**：歷史檢視完全唯讀。切換回合或篩選階段，不會覆寫交辦文字、改變最新回合、送出 AI 回覆，也不會清除輸入框中尚未送出的文字。檢視舊回合時隱藏最新回合的人工核定表單，按「回到最新回合」才恢復。

## 如何使用

將 `Multi-AI-v0.9-離線工作臺.html` 儲存到自己的電腦，以 Chrome 或 Edge 開啟。新增任務後，可依原本六階段流程操作。

完成一次人工核定，若選擇「退回重新討論」並填寫原因，按「開始本回合」即可進入第二回合。此時在「歷次討論／意見對照」切換到第 1 回合，就能比對前次答覆與人工退回理由；選擇「回到最新回合」可繼續第 2 回合。

**與 v0.8 備份相容：** 本版介面雖標示 v0.9，但底層仍沿用 `version: 8` 與 `format: multi-ai-offline-v0.8` 的 JSON 格式，不必遷移現有資料。可直接使用「還原 JSON 備份」匯入舊資料。本次純檢視功能不會改變 JSON 格式，也不會增加額外資料。

## 資料與安全事項

- 自動儲存使用瀏覽器 `localStorage`，可能因檔案路徑、瀏覽器、安全設定或無痕模式而無法使用；請注意右上角儲存狀態，定期匯出 JSON。
- 備份含原始工作文字、AI 回覆和個人審查理由，**未加密**，勿公開上傳至 GitHub，勿使用真實個案個資或機密文書測試。
- Word 只解析 `.docx` 的文字，不保留原始檔；圖片、特殊排版等不保證完整擷取。
- 網頁版手動貼回的回覆均標示「來源未驗證」。網站不會代替你登入 ChatGPT 或 Gemini。
- Cloudflare Worker/D1 版仍為開發程式，未部署、未上線。正式站的 Access 安全驗收與遠端備份仍待處理。
