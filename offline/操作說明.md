# Multi-AI 雙 AI 協作工作臺 v0.8.0｜離線版

> 版本：2026-10-20，單一 HTML 檔，**無須 Cloudflare、D1、API Key 或安裝伺服器**。
>
> 本版本是供自行操作的**離線輔助工作臺**；它無法直接控制 ChatGPT／Gemini 網頁，也不會產生 AI 答案。

## 快速使用

1. 將 `Multi-AI-v0.8-離線工作臺.html` 保存至電腦固定資料夾，使用 **Chrome 或 Edge** 開啟。
2. 在左側輸入任務標題、分類及交辦指令。可以直接貼入文字，或上傳 `.docx` Word 檔（**上限 3 MB**），讓瀏覽器自動擷取主文、常見段落及表格文字。上傳後請先核對擷取內容再建立任務。
3. 建立任務後，按「**開始本回合**」。每一步由系統產生完整提示詞；點「複製提示詞」貼到相應的 ChatGPT／Gemini 網頁，取得真實回答後貼回離線工作臺。
4. 六步順序為：ChatGPT 獨立分析 → Gemini 獨立分析 → ChatGPT 交叉審查 → Gemini 交叉審查 → ChatGPT 最終建議 → Gemini 最終建議。**網頁版帳號與離線工作臺不自動同步**。
5. 六份回覆完成後，由你決定採納、部分採納、不採納或退回重新討論。若退回，必須填寫理由，下一回合會保留退回要求。
6. 點「匯出紀錄（MD）」保存單一任務的完整歷程；點「備份 JSON」保存**所有任務**。JSON 可使用「還原 JSON 備份」匯入，匯入前會要求確認覆蓋現有任務。

## v0.8 新功能

- **本機自動儲存**：每次建立任務、貼入 AI 回覆、人工審查、刪除任務、選取任務時會嘗試將資料存入該瀏覽器的 `localStorage`。上方狀態提示可協助辨識是否成功；不保證無痕模式或所有瀏覽器允許儲存。
- **Word 文字擷取**：在瀏覽器端讀取標準 `.docx` ZIP 封裝中的 `word/document.xml`，透過內建解壓縮 API 處理。支援一般文字、換行、表格；不會完整保留版面、圖片、註解、追蹤修訂、公式或頁首頁尾；不支援舊版 `.doc` 和加密 DOCX。Word 原始檔不會被永久保存。
- **多任務管理**：可建立多個任務，按標題／指令／分類搜尋，依狀態篩選、選取、刪除。最多 100 個任務、每個任務最多 30 回合。
- **討論呈現**：兩欄對照 ChatGPT／Gemini 三階段內容，另有六步進度條。
- **備份與還原**：提供完整 JSON 備份／還原及單一任務 Markdown 匯出；JSON 備份沒有加密。

## 重要限制與資料安全

- **請勿用於真實少年個案、可識別個資、機密文書或敏感工作資料**：瀏覽器 localStorage 未加密，任何可接觸電腦帳號／瀏覽器資料的人可能存取內容。
- **自動儲存不等於永久備份**。清除網站資料、無痕模式、裝置損壞、移動 HTML 路徑、改用瀏覽器／電腦，都可能造成資料無法讀取。跨版本使用前，請先下載 JSON，再由新版還原。`localStorage` 亦可能因容量不足而儲存失敗，若上方顯示「儲存失敗」應立即匯出 JSON。
- 上傳 DOCX 時僅在本機解析文件，不會自動將檔案或文字傳送 Cloudflare／OpenAI／Google。但若你**自行把提示詞貼到 ChatGPT／Gemini 網頁**，該文字就會依那些服務的條款處理，請先確認資料是否適合分享。
- HTML 沒有外部 JavaScript 或 CSS 依賴；需要開啟外部網頁時，只有點「開啟對應 AI 網頁」才會進行。
- 目前的瀏覽器測試包含 Word 段落／表格解析、六階段流程、回合退回、MD／JSON 匯出與還原、任務搜尋，以及模擬瀏覽器儲存區的重新載入測試；**尚未在你的實際電腦進行跨次開啟的 localStorage 驗收**。

## 與雲端版關係

v0.8 是獨立離線版，**目前未合併到 GitHub 雲端主站程式，也沒有建立 Cloudflare 測試站**。日後若要使用 D1，需另外規劃資料匯入與安全權限，不能把這份 JSON 直接當成 D1 備份。
