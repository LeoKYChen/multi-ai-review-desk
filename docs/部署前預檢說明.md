# Cloudflare 部署前的無密碼預檢

本專案建立兩個獨立的 GitHub Actions 測試：

- `variables-preflight.yml`：驗證 `CLOUDFLARE_ACCOUNT_ID`（32 位十六進位字元）、`CF_D1_DATABASE_ID`（UUID）及 `ENABLE_STAGING_DEPLOY`（true/false）的格式。只讀取 Repository Variables，**不部署、不操作 D1**。
- `credentials-preflight.yml`：驗證 `CLOUDFLARE_API_TOKEN` 已設定、`OWNER_TOKEN` 至少 32 字元及 `OWNER_PASSWORD` 至少 16 字元。只輸出通過／失敗，**不輸出秘密值、不呼叫 Cloudflare**。

這些檢查**不等於**已驗證 Cloudflare API Token 權限或 Account/D1 所屬關係，也不代表 Cloudflare Access 已配置。

私人內容上傳前仍必須驗證 Cloudflare Access 限制僅本人、登入控制與 D1 端對端測試。

預檢成功後，僅能代表已具備下一階段部署的形式條件；應保留 `ENABLE_STAGING_DEPLOY=false`，直到部署安全措施經確認。
