# Cloudflare 測試站：部署啟動條件

此分支的 GitHub Actions 會在推送時自動執行：

- 格式檢查：Account ID、D1 UUID、部署開關。
- Secrets 檢查：只確認 Token 是否存在、登入憑證長度，不輸出內容。
- 只讀 Cloudflare API 檢查：僅對指定的 D1 資料庫發出 GET，確認帳號、資料庫名稱及 Token 的讀取權限。**不讀取資料表、不執行 migration、不部署 Worker。**

部署工作 `Deploy Cloudflare staging (opt-in)` **不再受 push 自動觸發**。未來必須由你在 GitHub Actions 手動執行，輸入 `deploy-private-staging`，且 `ENABLE_STAGING_DEPLOY=true` 才會開始。

目前請**維持 `ENABLE_STAGING_DEPLOY=false`**，直到確認 Cloudflare Access 或採取「沒有公開路由」的先部署後啟用方案。

登入、Word 文字擷取及 D1 還原測試尚未完成；不要在測試階段上傳工作機密、個案個資或真實敏感文書。
